# Seed repeats

Generated by `scripts/summarize_seeds.py`. `qv_r16` (the best adapter on Spider) was trained again from `configs/train/qv_r16_s<N>.yaml`, which differ from `qv_r16.yaml` only in the seed, the run name and the output directory. The seed sets the LoRA initialisation, the dropout masks and the data order together. Seeds scored: Spider 0, 1, 2; BIRD 0, 1, 2. Seed 0 is the run in the main tables. Qwen2.5-Coder-7B-Instruct, nf4 + bf16 compute, greedy decoding (repetition penalty 1.0, i.e. off).

"95% CI" resamples questions and "by database" resamples whole databases (5,000 resamples, seed 0). p-values are exact two-sided McNemar, unadjusted. With this few seeds the sample sd is a rough guide only.
